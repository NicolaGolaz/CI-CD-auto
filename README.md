# CI-CD-auto
## Description du projet
Petit outil automatique pour mettre en place rapidement un CICD générique de base utilisant "Github actions" sur les projets des étudiants de l'école. Utilisable pour les différentes stack techniques utilisées à l'ETML (exemple: Vite + React + Express).
Ce projet consiste à développer un outil en ligne de commande (CLI) intelligent destiné à automatiser la mise en place de pipelines CI/CD (Github Actions) pour les étudiants. La particularité centrale de l'outil est son moteur d'auto-découverte : il analyse la structure et les fichiers de configuration du repository cible (local ou via l'API Github) pour détecter automatiquement la stack technique (langages, frameworks comme Vite/React/Express, outils de tests, gestionnaires de paquets).
L'objectif est d'offrir une expérience "Zéro Config" : à partir de cette analyse, l'outil génère et écrit dynamiquement les fichiers workflows .yml adaptés, incluant les étapes de compilation, de linting et de tests spécifiques au projet détecté. C'est un défi technique complet qui combine logique algorithmique (parsing de fichiers package.json/composer.json), utilisation d'API et compétences DevOps, afin de standardiser et simplifier le déploiement des projets à l'école.
